누적 초과 거래대금: 업종이 평소(직전 6개월 평균 비중)보다 더 거래된 금액을 매일 더한 값입니다. 선이 오르면 매매가 계속 몰리는 중, 내리면 관심이 빠지는 중입니다.

거래대금은 매수 = 매도라 돈이 들어왔는지 나갔는지는 알려주지 않습니다. 방향은 RS(가격의 상대 강도)와 함께 봅니다.

RS(상대강도) = 업종·종목 수익률을 같은 시장(코스피 또는 코스닥) 수익률과 비교한 값입니다. (1 + 대상 수익률) ÷ (1 + 시장 수익률) − 1로 계산하고, +면 시장보다 강하다는 뜻입니다. 수익률은 KRX 등락률(분할 반영)을 이어 붙였고, 업종은 시가총액 가중입니다.

거래대금 × RS: 쌓임 · RS↑ 매수 우위 거래가 몰리며 가격도 시장보다 강함 · 쌓임 · RS↓ 가격 약세 거래는 몰리는데 가격은 밀림(손바뀜·매도 우위 가능) · 빠짐 · RS↑ 조용한 강세 · 빠짐 · RS↓ 이탈. RS가 ±1%p 안이면 시장 수준으로 봅니다.

투자자별 순매수(돈의 방향)는 KRX Open API 연결 후 추가됩니다.
